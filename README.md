# CliniDENT — Centro Odontológico — Site demonstração

Site conceito em **React + Vite** para a CliniDENT — Centro Odontológico,
em São Leopoldo/RS. Criado como demonstração para prospecção: usa os dados
públicos reais da clínica (endereço, WhatsApp, Instagram, Facebook,
horários e avaliação no Google), mas ainda não é o site oficial.
